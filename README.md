# aibuilders.online

Marketing site for AI / Builders — a one-person AI build studio out of Chicago.
Custom AI products for real estate, finance, and SMBs. Two-week sprints, no retainers.

## Stack

Pure static HTML/CSS/JS, single file (`index.html`), deployed to Vercel.

- Fonts: Fraunces (display), Manrope (body), JetBrains Mono (kickers)
- No build step, no dependencies

## Local development

Open `index.html` directly in a browser, or serve the folder:

```bash
npx serve .
```

## Deployment

Pushes to `main` deploy automatically via Vercel.
Domain: [aibuilders.online](https://aibuilders.online)
